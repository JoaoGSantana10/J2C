Visão Geral

Contexto, motivação e escopo do compilador J2C

Contextualização

Entender como um compilador é construído — da análise léxica à geração de código — exige aplicar na prática as etapas clássicas do pipeline de compilação sobre uma linguagem real.

Motivação

O J2C nasce como projeto prático da disciplina de Compiladores 1, para consolidar os conceitos de análise léxica, sintática e geração de código com Flex e Bison.

Objetivo Geral

Construir um compilador que reconheça um subconjunto da linguagem Java e traduza esse código para C equivalente, executável com GCC ou Clang.

Escopo

Tipos primitivos, estruturas de controle, funções e operadores padrão — sem orientação a objetos, por enquanto.

Pipeline de Compilação

1

Análise Léxica

Reconhecimento de tokens com Flex

2

Análise Sintática

Validação da gramática com Bison

3

Análise Semântica

Tabela de símbolos e checagem de tipos

4

Geração de Código

Tradução para C equivalente
